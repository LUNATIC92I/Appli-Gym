# Bienvenue, jeune développeur ! {#bienvenue}

::: chapitre-intro
Bonjour ! 👋 Tu tiens entre tes mains un cours pour apprendre à créer de **vraies pages web**, belles, colorées et qui s'adaptent à tous les écrans : téléphone, tablette et ordinateur. Tu n'as besoin de **rien savoir** au départ. On va avancer pas à pas, comme quand on apprend à faire du vélo : d'abord avec les petites roues, puis tout seul !
:::

## Comment utiliser ce cours ?

Ce cours est découpé en **18 chapitres**. Chaque chapitre ressemble à un petit niveau de jeu vidéo :

1. 📖 **On découvre** une nouvelle notion, avec des exemples de la vie de tous les jours.
2. 💻 **On regarde du code** : chaque ligne est expliquée.
3. 🖥️ **On voit le résultat** : sous chaque exemple, une image montre exactement ce qui s'affiche dans le navigateur. Ces images ont été fabriquées en faisant vraiment tourner le code avec Bootstrap 5.3 : tu peux donc avoir confiance, le code fonctionne !
4. 🧩 **On s'entraîne** avec trois exercices : ⭐ facile, ⭐⭐ moyen et ⭐⭐⭐ avancé. Chaque exercice a un objectif, des consignes, des indices et une solution expliquée.
5. ❓ **On se teste** avec un quiz de 5 questions (les réponses sont juste après).

À la fin, tu construiras **un site complet pour une école** : barre de navigation, bannière, galerie, cartes des enseignants, formulaire de contact et pied de page. Tu pourras le montrer fièrement à ta famille et à tes amis !

## De quoi as-tu besoin ?

- Un **ordinateur** (Windows, Mac ou Linux, peu importe).
- Un **navigateur web** récent : Google Chrome, Mozilla Firefox, Microsoft Edge ou Safari.
- Un **éditeur de texte** pour écrire ton code. Nous te conseillons **Visual Studio Code** (gratuit, il s'appelle souvent « VS Code »). Le Bloc-notes de Windows fonctionne aussi pour commencer.
- Une **connexion Internet** : Bootstrap sera chargé depuis Internet (on verra comment au chapitre 2).

::: astuce
Demande à un adulte de t'aider à installer Visual Studio Code la première fois. Ensuite, tu pourras travailler tout seul !
:::

## Petit vocabulaire de départ

| Mot | Ce que ça veut dire |
|---|---|
| **Page web** | Un document que ton navigateur affiche, comme la page d'accueil de ton jeu préféré. |
| **Navigateur** | Le programme qui affiche les pages web (Chrome, Firefox, Edge, Safari…). |
| **Code** | Des instructions écrites dans un langage que l'ordinateur comprend. |
| **Balise** | Un mot entre `<` et `>`, comme `<p>`, qui dit au navigateur ce qu'est un morceau de texte. |
| **Classe** | Une étiquette qu'on colle sur une balise avec `class="..."` pour lui donner un style. Bootstrap fonctionne presque entièrement avec des classes ! |
| **Fichier .html** | Le fichier qui contient ta page web. |
| **Responsive** | Se dit d'une page qui s'adapte toute seule à la taille de l'écran (on dit aussi « adaptative »). |

::: retenir
Pour apprendre, **le plus important est de taper le code toi-même** plutôt que de le copier-coller. Tes doigts retiennent aussi ! Et si quelque chose ne marche pas du premier coup, c'est normal : même les développeurs professionnels font des erreurs tous les jours. 😉
:::
