Ce module porte sur **Microsoft Defender XDR** et ses composants : portail, incidents et corrélation, notifications et ajustement des alertes, analyse des menaces, chasse avancée, Security Copilot ; **Defender for Endpoint** (fonctionnalités avancées, ASR, groupes d'appareils, niveaux d'automatisation, collecte personnalisée, actions de réponse, Live Response) ; **AIR et interruption automatique d'attaque** ; **Defender for Office 365** ; **Defender for Identity** ; **Defender for Cloud Apps** ; **Microsoft Entra ID / ID Protection** ; **Microsoft Purview** (audit, eDiscovery, DLP, risques internes) et **journaux d'activité Microsoft Graph** ; **règles de détection personnalisées**.

Les questions de configuration relèvent du domaine officiel 1, les questions d'investigation et de réponse du domaine 2, et les questions de chasse du domaine 3.
